✅ Langkah-Langkah Sinkronisasi

  1. Buka aplikasi di browser: http://localhost:1500
  2. Buka Admin Panel (tombol kunci 🔐 atau panel admin)
  3. Gunakan Password Admin: 9380
  4. Scroll ke bagian "Sinkronisasi Data" atau Admin Tools
  5. Klik tombol "Sinkronisasi dari Firebase"
  6. Data akan ter-update otomatis

Jika data tetap tidak sinkron:

  2. Atau buka Developer Tools → Application → Clear All Site Data
  3. Reload halaman
  4. Firebase listener akan pull data terbaru
